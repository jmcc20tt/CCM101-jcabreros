# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using the KillerCoda Playground. The mission focused on learning basic Linux operations, system information gathering, file and directory management, and creating a professional Cloud Computing portfolio using GitHub.

## Objectives

- Access and use a cloud-based Linux environment.
- Explore and navigate the Linux operating system.
- Gather basic system information.
- Organize files and directories using Linux commands.
- Create and maintain a GitHub repository.
- Document technical work using Markdown.

## Activities Performed

I accessed the Ubuntu Linux environment through KillerCoda, created a new Linux user, logged in to the new account, and checked the username, working directory, and hostname. I also gathered information about the Linux distribution, kernel, CPU, memory, and disk space. I created directories and a Markdown file for my Cloud Computing portfolio.

## Linux Commands Used

- sudo adduser – Created a new Linux user.
- sudo usermod -aG sudo – Added the user to the sudo group.
- su - – Logged in to the new user account.
- whoami – Displayed the current username.
- pwd – Displayed the current working directory.
- hostname – Displayed the hostname.
- cat /etc/os-release – Displayed Linux distribution information.
- uname -r – Displayed the kernel version.
- lscpu – Displayed CPU information.
- free -h – Displayed memory information.
- df -h – Displayed available disk space.
- mkdir – Created directories.
- cat – Displayed the contents of a file.

## Skills Learned

Through this activity, I learned how to access and work with a cloud-based Linux environment, use basic Linux commands, gather system information, organize files and directories, and document my technical work using Markdown and GitHub.
