# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

AWS is recommended for the startup because it provides a wide range of cloud services that can support a new mobile application. The startup has a limited budget, so it can use cloud resources according to its current needs and scale them as the application grows. AWS also provides services that can support application hosting, storage, and databases. This makes AWS a flexible option for a growing startup.

### Recommended Services

- Amazon EC2 – Compute
- Amazon S3 – Object storage
- Amazon RDS – Relational database

---

## Client B – University

### Recommended Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies, which can make cloud migration easier. The university can use Azure services to support its existing infrastructure and applications. This makes Azure a suitable choice for the university.

### Recommended Services

- Azure Virtual Machines – Virtual servers
- Azure SQL Database – Managed database
- Microsoft Entra ID – Identity and access management

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform (GCP)

Google Cloud Platform is recommended because the company develops Artificial Intelligence and Machine Learning applications that require high-performance computing. GCP provides cloud services designed for AI, machine learning, and large-scale computing workloads. These capabilities can help the research company develop and run its AI applications. GCP is therefore a suitable platform for this type of research workload.

### Recommended Services

- Compute Engine – Virtual machines and computing
- Google Kubernetes Engine (GKE) – Kubernetes management
- Vertex AI – AI and Machine Learning platform

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

AWS is recommended for the global e-commerce company because it provides a broad range of services for highly available and scalable applications. The company serves customers around the world, so it needs infrastructure that can handle changing workloads and maintain availability. AWS provides services for computing, storage, networking, and automatic scaling. These capabilities make AWS suitable for a large global e-commerce application.

### Recommended Services

- Amazon EC2 – Compute
- Amazon S3 – Object storage
- Elastic Load Balancing – Distributes application traffic


## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | AWS provides a wide range of services and allows startups to scale their resources as their application grows. |
| Enterprise Organization | AWS | AWS offers a broad selection of cloud services that can support different enterprise workloads and requirements. |
| Microsoft Environment | Microsoft Azure | Azure provides strong integration with Microsoft technologies such as Windows Server, Microsoft 365, and Active Directory. |
| AI / Machine Learning | Google Cloud Platform | GCP provides strong capabilities for Artificial Intelligence and Machine Learning workloads. |
| Kubernetes Deployment | Google Cloud Platform | GCP provides Google Kubernetes Engine (GKE), which is designed for deploying and managing Kubernetes workloads. |
| Global Web Application | AWS | AWS provides global infrastructure and scalable services that can support applications serving users around the world. |
